## 2024-06-16 - Java Swing ARIA-Equivalent Accessibility & Mnemonic Conflicts
**Learning:** In Java Swing desktop applications, screen reader support and keyboard accessibility (similar to HTML ARIA attributes) are achieved by setting component properties such as `setToolTipText()` and `setMnemonic()`. A critical finding is that when adding mnemonics (keyboard shortcuts via `Alt + Key`), extreme care must be taken to ensure they are unique within the same view to prevent keyboard navigation conflicts. For instance, assigning 'F' to a 'Favorite' button can disrupt the standard `Alt+F` shortcut for 'File' menus.
**Action:** When improving accessibility in Java Swing, consistently apply `setToolTipText()` for screen readers and `setMnemonic()` for keyboard navigation. Always cross-reference the chosen mnemonic keys against existing menu bar shortcuts and other components in the same view to prevent conflicting behaviors.
