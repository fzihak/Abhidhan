## 2024-06-14 - Keyboard Accessibility and Screen Reader Support in Java Swing
**Learning:** In Java Swing desktop applications, `setToolTipText()` and `setMnemonic()` are critical for accessibility. They serve a similar purpose to ARIA labels and HTML `accesskey` properties. Tooltips provide context for screen readers and mouse users on icon-only or ambiguous buttons. Mnemonics (e.g., `Alt+S`) enable quick keyboard navigation without tabbing through the entire interface. It is essential to ensure mnemonics are unique within the view to avoid conflicts (e.g., avoiding `Alt+F` for a 'Favorite' button to prevent overriding standard 'File' menu shortcuts).
**Action:** When creating or modifying Java Swing components, consistently apply tooltips and non-conflicting mnemonics to main interactive elements to ensure screen readers and keyboard users have a seamless experience.
