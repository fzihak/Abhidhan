## 2026-07-27 - Keyboard Submission in Java Swing vs Web Forms\n**Learning:** In Java Swing views, unlike web forms where pressing 'Enter' in a text field typically triggers a form submission automatically, this native behaviour does not exist by default. It requires manual setup.\n**Action:** Use `getRootPane().setDefaultButton(button)` to enable standard keyboard submission UX. Wrap this call in `SwingUtilities.invokeLater()` to prevent NullPointerExceptions, as the root pane might be null during early component initialization.
